Each section opens with a short boxed passage written for the reader: a scene and the section's thesis in brief. A
reader can then type a message, which gets an answer, or press Return with nothing typed, which carries the reading on
with the next ideas the text holds. The first Return treats the box as a prologue and begins at the first passage;
later Returns resume from where the conversation has reached. When a section's material is exhausted the text signals
completion, and a further Return moves to the next section.
